# UDS DID catalog

Data Identifiers for UDS service 0x22 (ReadDataByIdentifier). ISO-standard DIDs (0xF180–0xF19E) are [A] per ISO 14229-1:2013 — the standard fixes number and name, not record length. Nissan entries are KWP2000-style 0x21 local IDs, not 0x22 DIDs. Hyundai DID numbering is ECU-scoped — always pair the DID with its ECU.
