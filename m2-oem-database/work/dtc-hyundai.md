## Hyundai/Kia DTC quirks

1. **KWP2000-era vs UDS-era code behavior.** On 2005–~2011 CAN vehicles (KWP2000 application layer), many P16xx serial-communication codes (P1600–P1604) predate UDS and read out through the KWP2000 session; a UDS-only tool may misreport or miss them. [B — HiCOM protocol timeline, from the v1.1 Hyundai research]
2. **Same code, different module.** B1101/B1102 and C1101/C1102 appear in SRS, ESP/ABS, and MDPS contexts with identical descriptions — always identify the reporting module before diagnosing. [C]
3. **Application-dependent P-code meanings.** TechNet lists multiple fault locations for single codes (P1500–P1504, P1515/P1516, P1605/P1606/P1608, P1615, P1621, P1679, P1698). The meaning depends on model/engine/year — never assume one variant. [A — Hyundai TechNet Times]
4. **SMARTRA immobilizer family.** P1610/P1642 (ECU/BCM mismatch), P1688 (lock), P1689 (unregistered transponder), P1690–P169A (SMARTRA/antenna/auth), P1699 (twice overtrial lockout). Key learning needs GDS plus the PIN code; P1699 means the immobilizer has locked after repeated failed attempts. [A/B]
5. **DMTL, not EGR, on modern P1401.** TechNet defines P1401 as DMTL (tank-leakage diagnostic module) on current vehicles, but early-2000s Accents report P1401 as an EGR fault — year-dependent. [A/C — conflict reported]
6. **Variant coding is mandatory.** C1702 (variant coding error), B1637 (system not initialized), B1661 (parameter missing) — replacement modules must be coded with GDS or these codes persist. [C]
7. **SRS crash codes are one-shot.** B1650–B1658 record a crash permanently; the SRS ECU must be replaced, not cleared. [C]
8. **Main-relay tip.** An open main relay with the engine running can set P0638/P0685/P1295/P2106 as a group — check the relay before replacing throttle components. [B — autohex Hyundai DTC help]
9. **Hyundai/Kia never used J1850** — all of the above are CAN/K-line codes; no VPW/PWM variants exist. [B — v1.1 research]
